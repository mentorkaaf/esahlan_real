🍎 iOS — com.esahlan.user ⚙️ GitHub Actions macos-14 🚀 Fastlane Match + TestFlight 📅 2026-08-28
💡
Sababta ugu wanaagsan: Mac ma baahid. GitHub Actions-ku cloud-ka macOS runner bilaash ah buu isticmaalaa. Adiga oo Windows-ka fadhida, iOS build + TestFlight upload all-automatic ah ayuu u diri doonaa.

1 Apple Developer Program Enroll ($99/sanad)

🌐 developer.apple.com/enroll
  1. Safari ama Chrome ku fur: https://developer.apple.com/enroll
  2. Apple ID-gaaga ku gal (haddii aadan lahayn, create garee)
  3. "Enroll as an Individual" dooro (haddii shirkad aad tahay: Organization)
  4. $99 bixi — credit card ama Apple Pay
  5. 24-48 saacadood gudaheed Apple approval soo dirtaa email-ka
⚠️
Approval-ka emaillka mentorkaafi@gmail.com u imaanaysaa. Hubi spam folder-ka.

2 App Store Connect API Key (GitHub Actions u baahan)

🔑 App Store Connect → Users & Access → Keys
  1. Fur: https://appstoreconnect.apple.com
  2. Users and Access → Keys tab
  3. "+" → Name: GitHub Actions → Role: App Manager → Generate
  4. Download .p8 file — hal mar keliya la download garayn karaa, ka kaydi!
  5. Note ku qor: Key ID (10 chars) + Issuer ID (UUID)
✅
.p8 file-ka hubi in aad ku kaydsatay secure meelsha — lost hadduu noqdaa cusub waa la sameeyn karaa laakiin secrets waa in dib loo update gareeyo.

3 Private GitHub Repo (Fastlane Match Certificates)

📦 github.com → New Repository
  1. GitHub.com → "+" → New repository
  2. Name: esahlan-certificates
  3. Visibility: Private (muhiim — certificates public ma noqon karaan)
  4. Create repository → URL-ka kopyee: https://github.com/mentorkaafi/esahlan-certificates

Fastlane Match wuxuu halkaas ku kaydinayaa certificates iyo provisioning profiles si automatic ah. Adigu ma galin — automatic ayuu u shaqaynayaa.

4 GitHub Secrets ku Dar (6 Secret)

🔒 GitHub → esahlan_real → Settings → Secrets → Actions

Path: github.com/mentorkaafi/esahlan_real → Settings → Secrets and variables → Actions → New repository secret

Secret Name Maxay tahay + Sideed u hesho
ASC_KEY_ID App Store Connect Key ID (10 chars). Step 2-da la helay.
ASC_ISSUER_ID App Store Connect Issuer ID (UUID format). Step 2-da la helay.
ASC_KEY_CONTENT .p8 file-ka content base64-encode garee:
Windows PowerShell: [Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\path\AuthKey_XXXX.p8"))
MATCH_PASSWORD Password aad doranayso certificates encrypt-garaynta. Example: eSahlan2026Match!. Ku qor meelsha.
MATCH_GIT_BASIC_AUTH username:token → base64. Token: GitHub → Settings → Developer settings → Personal access tokens → Classic → repo scope.
PowerShell: [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes("mentorkaafi:YOUR_TOKEN"))
GOOGLE_SERVICE_INFO_PLIST_BASE64 GoogleService-Info.plist → base64:
PowerShell: [Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\...\GoogleService-Info.plist"))

5 Fastlane Match — Certificates Initialize (hal mar)

⚙️ GitHub Actions → "match init" run (hal mar keliya)

Marka ugu horreysa certificates-ka la sameeynayo, GitHub Actions workflow cusub oo kale waxaad u baahan tahay ama Mac computer friend kaa leh. Beddelka, waxaad samayn kartaa:

  1. GitHub → Actions → workflow-ka → Run workflow
  2. Marka u horreysa shaqeynayso, Fastlane Match wuxuu ku weydiinaayaa certificates cusub in la sameeyo — wuxuu automatic u samaynayaa
  3. Haddii error soo baxdo "no certificates found": workflow log-ka fur, message-ka akhri
⚠️
Fastlane Match-ku wuxuu Apple Developer Portal-ka ku lognaan doonaa API key-ga adiga laga helay — tani ma baahna manual intervention.

6 Workflow Run — TestFlight Upload

🚀 GitHub → Actions → iOS — Build & Upload to TestFlight
  1. Fur: github.com/mentorkaafi/esahlan_real
  2. Tab: Actions
  3. Left sidebar: "iOS — Build & Upload to TestFlight"
  4. Button: "Run workflow" → Branch: main → Run workflow
  5. ⏱️ 20-35 daqiiqo sug — Flutter build + Xcode archive + upload
  6. Marka dhammaato: App Store Connect → TestFlight → build cusub muuqanaysaa
✅
TestFlight-ka build soo gaadhay marka: App Store Connect → "Submit for Review" riix → Apple review 1-2 maalmood → App Store LIVE! 🎉
